# Internationalization

Install a translation adapter once on the Vue app. The plugin only provides the
adapter and does not register or load library components.

```ts
import { createComponentLibrary } from '@sutekitechid/sicoco-v3-next'
import { i18n } from './i18n'

app.use(createComponentLibrary({
  i18n: {
    t: (key, params) => i18n.global.t(key, params),
  },
}))
```

`TranslationAdapter`, `LibraryTranslationKey`, `LibraryTranslationParams`,
`LIBRARY_I18N_KEY`, and `useLibraryI18n()` are exported from the package entry.
The adapter is required by components that use translated library copy. An
informative error is thrown if the plugin has not been installed.

Date picker month names, week days, and formatted dates use its `locale` prop,
which accepts a BCP-47 locale such as `id-ID` or `en-US`:

```vue
<SDatePicker locale="en-US" />
```

Keep the consumer translation function reactive. For example, `vue-i18n`'s
`i18n.global.t` tracks its active locale, so component labels are refreshed when
the locale changes.
